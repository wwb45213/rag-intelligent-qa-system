# RAG 智能问答系统
基于检索增强生成（RAG）技术的本地智能问答系统，支持本地文档解析与向量检索，结合大模型实现精准的文档内容问答，有效降低大模型幻觉问题。

## 技术栈
- 编程语言：Python
- 核心框架：LangChain
- 向量数据库：FAISS
- 大模型适配：支持主流大模型接口调用
- 后续规划：Gradio 可视化交互界面

## 核心功能
1.  **多格式文档解析**：支持 TXT 等格式文档的自动加载、语义切分
2.  **向量检索引擎**：自动构建文档向量库，基于语义相似度精准匹配相关上下文
3.  **增强式问答生成**：将检索到的文档片段作为上下文，引导大模型生成贴合原文的准确回答
4.  **本地私有化部署**：全程本地运行，支持自定义大模型密钥、向量库参数与文档目录
